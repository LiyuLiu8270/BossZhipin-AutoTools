# 易用性原型比较

独立的交互探索，不替换 1.0.0 正式界面。全部岗位、公司、背调与沟通记录均为虚构演示；不连接数据库、BOSS 或模型，不会发出真实消息。状态仅在当前页面内存保存，刷新重置。

## 打开方式

在仓库根目录运行 `node scripts/serve-usability-prototypes.mjs`，打开以下任一链接。顶部可以切换方案。

| 方案 | 入口 | 主要区别 |
| --- | --- | --- |
| A 效率列表 | http://127.0.0.1:17461/?v=a | 默认值得沟通，紧凑多列列表，点击打开详情抽屉 |
| B 待办优先 | http://127.0.0.1:17461/?v=b | 默认待我处理，优先展示 HR 回复与发送结果待确认 |
| C 连续阅读 | http://127.0.0.1:17461/?v=c | 桌面左侧列表、右侧常驻详情，便于连续比较 |

三版均含岗位机会、自动任务、我的简历、偏好与设置四页。保留列表形式，不采用岗位卡片墙。

## 建议体验

1. 搜索岗位，调整薪资与招聘者活跃筛选，查看空结果与重置。
2. 打开岗位，切换匹配判断、公司背调、岗位原文与沟通记录。
3. 体验模拟只打招呼、HR 回复、AI 托管及人工接管；发送结果未知时先核对，不重复发送。
4. 在自动任务中模拟登录恢复、独立暂停背调等操作。
5. 在设置中修改风格后切页，观察未保存提醒和保存后的保留效果。

任务计划保存、简历换版及报告均为演示，不能据此证明真实业务链路已经实现。

## 验收

执行 `node scripts/verify-usability-prototypes.mjs`（需要本机 Edge）。使用独立临时浏览器，不复用生产登录态。

本次验收覆盖三版的四页、筛选、报告、模拟沟通、接管、发送核对、任务恢复及设置未保存保护；覆盖 1366×900、1920×900、410×650。报告和截图写入被忽略的 `artifacts/usability-prototypes/`。

验收已通过：无横向溢出、无运行时错误、无外部请求、无生产请求与真实 HR 消息。已修复 A/B 过多顶部留白、C 底部操作不可见及筛选后误切换选中岗位。此为交互与布局验证，不是用户可用性研究或生产端到端验证。
