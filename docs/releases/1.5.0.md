# 1.5.0 · 2026-10-07

公司背调支持 Codex 自主调用隔离浏览器，不再要求原生搜索服务可用。真实浏览器搜索、原网页读取和报告推理由模型自主选择；软件只提供工具、任务调度和结果存储。

浏览器与 BOSS 采集/消息分离，临时未登录 profile，仅有公开网页搜索与读取；不开放私人浏览器、表单提交、消息发送、本地文件或 shell。模型配置和已有自动开关不改变，匹配与打招呼不获得新增工具。

旧原生搜索阻断归档，新能力仍先单路验证；保留失败报告和原始诊断。不把有报告等同于事实已被独立核实。

运行方式见 [公司背调](../公司背调.md)。实测结果见 [验收记录](../验收-1.5.0.md)。
