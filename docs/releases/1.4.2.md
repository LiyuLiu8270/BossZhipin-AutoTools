# 1.4.2 · 2026-10-07

本版修复来自实机内容验收，而非仅检查状态转换。

## 消息真实性

BOSS 的竞争者 PK 推广卡片使用 `item-friend`，且消息元数据携带招聘者 ID，不能据此认定为 HR 发言。现在交叉核对特定类型 `bizType=317`、`bodyType=16`、`messageType=articles`、相同消息 ID 和渲染卡片标题，将其保留为系统提示，不进入 HR 回复队列和模型输入。不广泛忽略其他卡片；未知非文本消息仍由本人核对。

旧记录只有在真实重新读取确认后才更正，并写入 `comm_message_corrections` 保存原记录，保留首次读取时间。身份变化、内容冲突等保护不放宽。此次不恢复暂停的托管，不发送测试消息。

## 简历评价

沿用 1.4.1 的 schema 快照修复。当前实际导入简历已通过真实模型服务重新评价，并逐项对照原文检查职责归属、项目阶段、指标解释、建议及证据。评价分仅表示表达与证据质量，不是录用概率；没有外部核验简历中各项业绩。

详细证据与限制见 [验收报告](../验收-1.4.2.md)。私有简历、会话及运行证据只保留在忽略目录，不提交 GitHub。
