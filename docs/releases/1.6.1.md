# 1.6.1

自动任务 → 批量生成招呼快捷入口 → 选择匹配建议和数据集 → 重新生成打招呼 → 确认数量。

支持优先沟通、可以尝试、低优先级、不匹配多选，默认前两档。默认跳过已沟通过的岗位，可显式包含。生成中和已排队不会重复加入，旧草稿保留至新结果成功。范围变化需重新确认；失败重试沿用招呼开关，不重匹配、不发送。

这是手动批次，自动生成关闭也会处理；并发及每日额度不变，额度用完保留排队。普通自动生成仍仅针对前两档。

岗位机会列表新增“采集时间”，直接显示最近列表/详情采集的北京时间，不是发布时间；未知显示“未记录”。无数据库表结构变更，不批量触发用户任务，未发布 GitHub。
