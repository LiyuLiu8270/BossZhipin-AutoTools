# 1.3.3 公司名称搜索

日期：2026-10-07。

原搜索只包含岗位名、招聘显示名和地区，导致有工商全称却搜不到中文公司名。现在补充已核实、来源绑定的工商全称，并在同数据集同公司主页且唯一已核实主体的范围内共享名称检索。例如一条详情确认中文全称后，同主页其他尚未补工商资料的岗位也可以被该全称检索。

兼容英文大小写、全半角与空格；不猜拼音、简称翻译或母子公司关系。多主体冲突、猎头代招、跨公司主页和跨数据集不自动关联。原有视图、薪资、活跃等条件仍叠加，先搜索再分页。

索引为派生内存数据，随岗位表变化失效，无数据库迁移，不修改原始公司、模型指纹、背调报告或人工记录，不新增模型或联网操作。回归覆盖名称关联、来源绑定、冲突排除、缓存失效与分页筛选。未自动发布GitHub。
