# 1.2.0：自动任务中的多路公司背调

入口：**自动任务 → 公司背调**。可查看在途公司/耗时、队列统计、配置背调并发与暂停/继续；设置页只保留跳转。

## 并发规则

- 默认跟随模型总并发，支持独立1–16路上限。原配置缺省按跟随处理，不写入或改变现有总上限。
- 所有自动模型任务共用总并发；背调上限不是额外增加的一池名额。单个公司全流程占用一个名额，完成即补下一家，不等整批。
- 同公司不重复领取，来源与观察隔离；不减少检索轮次和证据核验。
- 调高即补位；调低、暂停及正常停服允许在途完成，禁止新领取。停服等待所有在途任务后关库。
- 每次背调尝试计一次共享日额度，失败也计；并发不突破剩余预算。每家公司可能有多轮模型调用，费用与吞吐并非固定或线性关系。

## 升级与兼容

无表结构迁移，不删岗位、原简历、匹配、背调报告及人工记录。不更改autoAnalyze、背调开关、总并发/额度或关键词。已有开启背调的实例升级后会按现有总并发并行执行，单位时间负载会提高；可单独调小背调上限。

按正常停服等待在途结束，做SQLite一致性备份后升级；不以强杀进程代替排空。

## 验证与发布边界

单元/集成测试覆盖持续补位、共享占用、动态调整、失败释放、剩余额度、同公司去重及关闭等待。隔离Edge UI覆盖四页和1366/1920/410宽度，实测合成2路并行、快任务完成补位和暂停。

合成验收不调用真实模型、不发送HR消息；本机实际并发占用另行检查。未自动推送GitHub或创建远端标签/Release。
