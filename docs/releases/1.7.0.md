# 1.7.0

发布日期：2026-10-08。本次从上一个公开版本 0.13.0 更新，包含此前本地 1.0.0–1.6.1 的累计改动。

## 相对上个公开版本

- 新增公司背调与工商主体核对，支持报告查看、下载、独立并发及公开浏览器检索；不携带招聘平台登录态或私人简历。
- 新增逐岗位明确授权的“AI托管 / 只打招呼”、消息去重、提醒和人工接管；发送结果不明不自动重发，不自动投递附件。
- 更新四页交互、列表与详情抽屉、待办视图、公司全称搜索及采集时间。
- 分离自动匹配与自动招呼开关，支持单岗及批量重新生成；详情异常按单岗位隔离，并完善诊断与性能。
- 简历解析与评分复用已保存的匹配 Skill；搜索关键词由用户确认后加入。

## 本版调度与草稿

模型请求按固定优先级统一调度：HR 回复 → 人工操作 → 首次招呼 → JD 匹配 → 后台背调。人工操作包括单岗位/批量重写招呼和简历评分、岗位方向分析；首次沟通优先于自动招呼草稿。

没有等待补偿，也不会中断正在运行的任务。完成一个立即释放并补充一个，不等整批结束。高优先级持续积压时低优先级可能一直等待。

有已授权活动沟通且总并发大于 1 时，预留一路给沟通，其他任务不得占用；无沟通任务不预留。单并发不预留，新增授权不会抢占已运行任务。此规则不等于承诺即时发现或回复所有 HR 消息，浏览器读取仍串行。

简历分析纳入共享并发与每日额度。任务页显示真实总占用、简历分析占用和预留数量；排队中的简历分析明确显示等待名额。软件额度按任务次数统计，不是模型服务商的 token 速率限制。

招呼草稿直接保存模型最终纯文本，不要求 JSON、claims、事实编号或固定字数；完成仅表示生成成功，不代表软件已审核内容。空响应、请求失败、版本隔离及额度检查保留；AI 聊天检查不变。历史失败记录不自动重排。

自动任务使用互斥标签，保留输入草稿；匹配与招呼开关只在任务页控制，设置页保存额度不会覆盖这些开关。

## 升级与边界

1.7.0 调度本身没有数据库结构变更；从 0.13.0 升级包含中间版本新增的沟通、背调等表。升级前正常退出旧服务并制作一致性备份；勿只复制运行中的 SQLite 主文件。保留配置、人工记录与既有结果，不自动扩大发送授权。

公司背调默认独立开启，已有符合条件的匹配结果可能进入背调队列并使用模型预算；关闭自动匹配不等于关闭背调。新安装的定时采集、自动匹配及自动招呼默认关闭。

仅发布源码与许可，不包含私人数据或登录态。本轮没有发送真实 HR 消息，也未重新验证真实模型内容质量或长期托管。发布回归见 [发布验收记录](../发布验收-1.7.0.md)。
