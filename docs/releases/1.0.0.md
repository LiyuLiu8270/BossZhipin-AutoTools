# 1.0.0 — 自动公司背调与逐岗 AI 沟通

日期：2026-10-03。本文件是发布说明，是否已推送/打tag/发布Release应以GitHub实际状态为准。

## 功能

- 自动为“优先沟通 / 可以尝试”岗位做公开公司背调；原文证据、来源和未知项随报告展示，可下载Markdown。
- 同公司去重、30天缓存、待核实主体、失败保留旧报告、有限重试及设置开关；背调不自动触发HR沟通。
- 整合逐岗“AI托管 / 只打招呼”、详情消息记录、提醒与人工接管。未授权不发送；不发附件、不承诺面试和薪资；未知结果不重发。
- 页脚/API/核心/托盘统一1.0.0；建立版本文档与发布检查。

## 升级注意

自动背调默认开启，已有符合条件的岗位纳入，独立于autoAnalyze；共享每日任务预算与并发，背调每次尝试计一次。数据仅新增表，不清理既有岗位、简历、备注。既有岗位不自动开启AI沟通。仓库外旧实例不自动迁移。

模型服务仍使用原配置；背调由 Codex 自主选词、选页、追查并生成报告，程序执行其受限 search/open 请求并验证引文；不依赖服务商原生搜索。一次任务最多6轮模型调用，任务预算不等于请求数或费用。搜索服务可能返回不相关结果、限制访问或缺少索引，明确显示证据不足，不承诺全量工商/司法资料。
