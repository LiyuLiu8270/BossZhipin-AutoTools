# 1.4.0 — AI 语义判断与自主背调

日期：2026-10-07。GitHub发布需另行执行；版本文档不代表已推送。

- 招呼草稿由AI结合完整简历做语义核查，移除默认关键词/数字标记否决；仍校验结构及引用出处。
- 匹配保持固定结论，改风格只重写招呼，不触发重新匹配。
- 简历评价采用 AI 动态维度与整体参考分，可定性分析，不再五项固定求和。
- 搜索词建议由用户确认加入，不自动扩张采集范围；既有词和停用状态不变。
- 背调仅传公司全称与任务，使用原生 Codex 联网；删除应用层搜索编排与质量公式，兼容历史报告。
- 首次单路能力验证，成功后按配置并发；联网异常持久暂停后续背调，防止反复消耗预算。
- AI聊天人工接管、敏感承诺及未知发送逻辑保持不变。

## 兼容性与迁移

新增 company_research_runtime 技术状态表，不删除岗位、简历、匹配或人工记录。招呼规则指纹更新，旧草稿保留在数据库但不作为新规则下的有效草稿，后续按已有开关/额度重新生成；既有匹配结论不失效。

当前配置的自定义模型原生联网实测尚未通过：未观察到成功 web_search，出现非预期 cua_repl/js 工具调用而失败。背调链路改造完成不等于联网已可用；不以模拟测试冒充真实公司背调成功。未更换模型服务、模型或账号。
