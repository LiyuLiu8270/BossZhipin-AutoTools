# 自动公司背调

适用版本：1.5.0。

## 职责划分

软件负责取得与岗位绑定的工商全称、排队、并发、缓存、技术错误处理及报告展示。提交给 Codex 的内容只有公司全称和“自主开展公开资料背调、生成中文报告、附来源并区分事实与未知”的任务。

Codex 自主决定查什么、怎么查、怎么分析以及报告结构。软件不拼搜索关键词、不解析 Bing/Sogou 搜索结果、不编排 search/open 轮次、不按引文数量或栏目覆盖套质量公式。旧版对应模块已移除，历史报告仍可阅读。

## 操作入口

“自动任务 → 公司背调”管理开关、并发、运行状态。在值得沟通岗位的详情中看报告、下载 Markdown、重新背调。同公司共享报告；猎头/代招不猜真实雇主。工商来源未取得或存在冲突时不发模型任务。平台展示的公司不等于最终劳动合同主体。

默认开启，独立于自动匹配；升级保留用户保存的开关。1–16路或跟随模型总并发，共享匹配/招呼/聊天的总名额及每日预算。完成立即补位；暂停不强杀在途任务。首次先用一路验证联网（浏览器或原生），成功后开放配置并发，不改变用户保存的并发数。

联网不可用或出现非预期工具调用时，持久保存技术阻断，停止后续背调但不关闭用户开关、不影响匹配/招呼。重启也不自动反复消耗额度。修复后在失败岗位详情点击重新背调，清除阻断并先做单路验证。1.5.0 仅归档升级前“原生搜索不可用”阻断，允许新浏览器能力探测，其他错误不自动清除。

## 运行与证据边界

使用 `codex exec`，一家公司一个任务，任务内部检索与推理由 Codex 决定。只读沙箱，单次配置关闭 shell、插件/连接器及私人 MCP，并临时注册只读的 xunxu_public_browser。仅允许其 browser_search/browser_open 和可用的原生搜索事件，非预期工具调用使任务失败。不会修改全局模型/账号配置。

不再要求服务支持 Codex 原生联网，支持 MCP 工具调用即可通过浏览器检索。需要本机 Edge；使用新建临时 profile，不连接日常或采集浏览器，不提供私人登录态。公网代理对目标域 DNS 校验并固定公网连接地址；本机/内网、文件协议、BOSS 域不可访问。验证码、登录等限制不绕过，可由 Codex 选择其他公开来源。页面工具只支持打开和读取，不支持发消息、填写表单、任意脚本或下载文件。

工具将渲染文字与链接返回给 Codex，不对特定搜索引擎拼接公司关键词或排名。每次实际页面读取写入该公司的工作目录 browser-evidence.jsonl，含请求 URL、最终 URL、时间及页面文字，便于核实是否真读到了目标页面。已完成但返回错误/空内容的工具不作为联网成功证据。并发任务各自独立浏览器，较高并发会增加内存消耗。

“报告已生成”仅表示观察到检索任务完成并收到报告，不代表信息充分或事实经软件独立验证。模型允许明确报告资料不足；没有链接会显示提示，但不以链接数量替代语义判断。报告原文、引用链接、时间、任务事件保存在本地，可下载。页面以文本呈现，不执行模型生成的HTML。

正常报告30天复用；历史部分报告7天，待核实报告1天。技术瞬时故障最多3次退避，刷新失败保留旧报告及时间。未确认主体的旧空报告可重新排队一次；不清空公司、岗位或人工记录。

## 隐私与费用

不向背调任务发送简历、HR对话、Cookie或联系方式。任务输入仅公司全称，搜索由Codex调用其服务；模型和搜索服务会处理公开公司资料。一次背调尝试计一次每日任务预算，但可能包含多轮推理/搜索，不代表一次API请求或固定费用。

没有查到风险不等于没有风险；注册资本不等于营收，奖项不等于行业排名。报告是求职辅助，不是征信、法律或工商鉴证。重要事项请向HR及权威来源确认。

实现：`local/company-research.mjs`（调度）、`local/company-research-native.mjs`（保留兼容文件名，任务与报告）、`local/codex-runner.mjs`（Codex运行和事件记录）、`local/research-browser-mcp.mjs`（只读工具）、`local/research-browser.mjs`（隔离浏览器/公网代理）、`local/company-identity.mjs`（岗位工商主体）。
